    Cómo funciona

    De la pregunta al experimento en tres pasos

    1. 1

      Elige el área

      Busca por tema o por nivel: colegio o universidad. Cada aplicación indica para qué curso sirve.

    2. 2

      Ábrela en el navegador

      Funciona en la computadora, la tableta o el celular. No hay que crear una cuenta ni instalar programas.

    3. 3

      Experimenta y comprueba

      Cambia variables, compara con datos reales y exporta tus resultados para el informe de laboratorio.

    Para docentes

    Llévalo al aula

    Las aplicaciones están pensadas para proyectarse en clase y para que cada estudiante las use en su propio dispositivo durante el laboratorio o en casa.

    • Proyecta la simulación y cambia variables frente al grupo.
    • Comparte un enlace: los estudiantes no necesitan cuenta.
    • Exporta espectros, tablas e imágenes para guías y exámenes.
    • Propón una aplicación para tu curso y la evaluamos.

    Preguntas frecuentes

    Antes de empezar

    ¿Las aplicaciones son gratuitas?

    Sí. Todas las aplicaciones de QuímicaEduc son gratuitas para estudiantes y docentes.

    ¿Necesito instalar algo o crear una cuenta?

    No. Las aplicaciones se abren en el navegador (Chrome, Firefox, Edge o Safari, en computadora o celular) y no piden registro.

    ¿Para qué nivel están pensadas?

    Cada aplicación indica si es para colegio, para universidad o para ambos. Usa el filtro de nivel del catálogo para encontrar las de tu curso.

    ¿Puedo usar los resultados en mis informes?

    Sí. Varias aplicaciones permiten exportar imágenes, tablas y datos (por ejemplo, el analizador de RMN exporta PNG, CSV y JCAMP-DX). Cita la aplicación como fuente.

    ¿Qué significa “Próximamente”?

    Son aplicaciones en desarrollo. Aparecen en el catálogo para que sepas qué temas vienen y puedas proponer prioridades.
